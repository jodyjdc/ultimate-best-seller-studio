# Aviso de idioma · Language notice

GitHub é global e o público inclui builders de IA, escritores e editores fora do Brasil).

Leia a documentação principal:

- 🇬🇧 [`README.md`](README.md) — English (canonical)
- 🇮🇹 [`README.it.md`](README.it.md) — Italiano

  medido**, movido pelo [Better Humanizer](https://github.com/jodyjdc/better-humanizer).
